# Actions and analysis tools

Choose a workflow by its intended outcome.

| Task | Purpose | Context |
|---|---|---|
| [Threat hunting](menaces.md) | USB triage, format audit and antivirus | Operator, no case |
| [Analyze media](../analysis.md) | Inspect and document files | Operator and case |
| [Working storage](stockage.md) | Write results or transfer files | Read/write destination |
| [Forensic imaging](copie-forensique.md) | Acquire RAW, E01 or AFF | Read-only source |
| [Disk cloning](clonage.md) | Copy one disk to another | Target is overwritten |

Legacy interactive scripts may open in a graphical terminal. Read the exit summary before closing it. Use [the first investigation tutorial](../getting-started.md) if you are new to Vigil.
