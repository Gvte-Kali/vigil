# Configure Vigil

Before your first investigation, review the organization identity, operators and system protections. In the Qt GUI, settings are grouped under **System → Configuration**.

| Section | Purpose |
|---|---|
| [System and operators](systeme.md) | Organization identity, logo, operators, preferences and tools |
| [Cases and projects](projets.md) | Create, activate, archive and find investigations |
| [USB devices](peripheriques-usb.md) | Device inventory, trust/block lists and HID protection |
| [ClamAV signatures](../clamav.md) | Update and check signatures before scanning |

For a first run, follow [Your first investigation](../getting-started.md). Check USB settings on authorized disposable test media.
