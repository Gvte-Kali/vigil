# 📁 Projets

> Bouton **« Gérer les projets »** de la section Configuration —
> page `gui/vigil_project_manager.py`.

---

## 📖 En résumé

Les **projets** sont globaux (non liés à un utilisateur) mais un utilisateur
doit être sélectionné pour logger la chaîne de custody. Un projet actif est
**obligatoire** pour lancer une analyse de fichiers (exception : le scan
antivirus et la recherche de menaces restent autonomes).

La page permet la **création / modification / export** des projets.
